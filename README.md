# 📊 Smart Data Analytics & Data Science Automation Tool

## 📌 Project Overview

The **Smart Data Analytics & Data Science Automation Tool** is a Python-based web application developed using Streamlit. It helps users import, clean, analyze, visualize, and forecast data through an interactive dashboard.

The application simplifies data analysis and generates useful insights from datasets.

## 🚀 Features

* 📂 **Data Import:** Import datasets from CSV and Excel files.
* 🗄️ **MySQL Integration:** Connect to a MySQL database and load tables.
* 🧹 **Data Cleaning:** Handle missing values, remove duplicate rows, and trim extra spaces.
* 📊 **Data Visualization:** Generate line charts, bar charts, pie charts, donut charts, scatter charts, area charts, step charts, stem charts, and heatmaps.
* 📈 **Sales Forecasting:** Predict future values using the moving average method.
* 📑 **Report Generation:** View analysis reports and download results.
* 📥 **Data Export:** Download cleaned datasets, charts, forecasting results, Excel reports, and ZIP reports.

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* Matplotlib
* Seaborn
* MySQL Connector
* NumPy
* OpenPyXL
